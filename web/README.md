# 前端（第一个里程碑）

独立 Agent 的阅读界面。接口和分工见 [docs/agent-architecture.md](../docs/agent-architecture.md)。

现在能做的：左边显示论文，右边按字段显示讲解；原文上标出当前这一点；点“继续”讲下一个点；在原文上选中一段可以提问；点讲解里的位置标签会跳到原文；点“没展开的词”会把它填进提问框。

## 运行

不需要构建。在仓库根目录启动一个静态服务：

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory web
```

然后打开 <http://127.0.0.1:8765/>。

- 没有后端时，页面自动使用 `mock/` 里的样例数据，右上角显示“样例数据”。
- 加上 `?mock=1` 可以强制使用样例数据。
- 后端就绪后，由后端在同一个地址下提供 `/api/...`，页面会自动改用真实接口；用 `?paper=<arXiv 编号>` 指定论文。

## 文件

| 文件 | 作用 |
| --- | --- |
| `index.html`、`styles.css` | 页面骨架和样式，支持深色模式和窄屏。 |
| `js/api.js` | 接口层。真实后端和样例数据提供同一组方法。 |
| `js/paper.js` | 左侧论文：显示正文、公式和图注，标出讲解对应的位置，读取读者选中的原文。 |
| `js/cards.js` | 右侧讲解：把讲解对象显示成卡片。 |
| `js/rich.js` | 文字处理：转义、少量 Markdown、公式。论文和讲解的文字都当作数据，先转义再显示。 |
| `js/app.js` | 页面主逻辑。 |
| `mock/` | 样例数据，同时是后端结构校验的测试用例。 |

## 样例数据

- `mock/paper-2610.27436v1.json`：论文正文，取自 arXiv:2610.27436v1（Juan A. Cañas、Guo-Qing Zhang、A. Martín-Ruiz），按 CC BY 4.0 使用。行内公式是 arXiv HTML 的替代文字，图没有收录。
- `mock/explanations-2610.27436v1.json`：一份导读和两轮讲解，改写自 `examples/` 下的开发样例。读者背景和概念状态都是模拟的，不是真实阅读记录。
