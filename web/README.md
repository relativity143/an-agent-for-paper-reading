# 前端（第一个里程碑）

独立 Agent 的阅读界面。接口和分工见 [docs/agent-architecture.md](../docs/agent-architecture.md)。

现在能做的：左边显示论文，右边按字段显示讲解；原文上标出当前这一点；点“继续”讲下一个点；在原文上选中一段可以提问；点讲解里的位置标签会跳到原文；点“没展开的词”会把它填进提问框。重新打开页面时恢复已有的讲解和提过的问题。右上角的“论文”可以换一篇、打开本地 PDF；“后端”可以选用哪个模型。

## 运行

不需要构建，也不依赖外网：页面用到的库都在 `vendor/` 里。页面和接口由本地服务在同一个地址提供，在仓库根目录运行：

macOS 上双击仓库根目录的 `start.command`，它会启动服务并打开页面；关掉它的窗口，服务就停。也可以用命令行：

```sh
python3 -m server --open
```

默认地址是 <http://127.0.0.1:8765/>，用 `--port` 换端口。打开后在页面上输入 arXiv 编号、选一篇本机已有的论文，或者把 PDF 文件拖进来。模型后端在右上角选；API 后端的地址、模型和密钥要在本机的配置文件里填，见 [server/README.md](../server/README.md)。

服务只接受同源请求，所以页面不能放在另一个端口上去调它。

### 只看界面，不启动后端

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory web
```

这时页面连不上 `/api/health`，自动使用 `mock/` 里的样例数据，右上角显示“样例数据”。后端在运行时，加 `?mock=1` 也可以强制使用样例数据。页面只在启动时做这个判断，运行中途连不上后端不会悄悄切换。

### 联调：真实的服务，固定的输出

```sh
python3 web/dev/fixture_server.py --port 8766
```

它用 `server/` 的真实代码（HTTP、事件推送、显示回执、续读和校验），把模型换成固定输出。不联网，不调用模型，数据放在临时目录里，退出时删除，不碰真实的阅读记录。

加 `--delay 8` 会让每一轮先等 8 秒，用来看“生成中”时页面的样子。

- <http://127.0.0.1:8766/?paper=2610.27436v1>：HTML 论文，导读 → 两轮讲解 → 一次模型失败 → 主线结束。
- <http://127.0.0.1:8766/?paper=2601.00002v1>：只有 PDF 的论文，开场失败一次 → 导读 → 一轮讲解。

在这个服务上切换模型后端，选择会保存到临时目录，但讲解仍然是固定输出，不会调用模型。上传的 PDF 没有对应的固定输出，请求讲解会报错，这是预期的。

它只检查页面和后端的配合，不能说明真实模型的讲解质量。

## 和后端的配合

约定见 [docs/agent-architecture.md](../docs/agent-architecture.md) 第 4 节，页面这边的做法：

- **显示回执。** 一份讲解的卡片显示出来之后，页面才告诉后端“已显示”；从历史恢复的卡片也一样。后端收到回执才记日志、才往下讲。回执没发成时，卡片底部出现提示和“重试”，这之前“继续”不可用。
- **不重复显示。** 后端可能把同一份讲解再返回一次，页面按讲解编号去重。
- **不自动开始。** 打开一篇还没读过的论文时，页面不自动请求导读，等读者点“继续”。生成导读要调用模型，要等一两分钟，期间换不了后端。样例数据模式不调用模型，仍然直接显示导读。
- **等待。** 生成中显示已经等了多少秒。这时打开后端设置，会说明要等这一轮完成，完成后自动放开。
- **导读在先。** 一篇论文的第一轮总是导读。这时提的问题由后端留着，页面提示“点继续后回答”。
- **主线讲完。** 最新一份讲解没有“接下来”时，“继续”停用，仍然可以提问。
- **失败。** 模型没讲成时显示原因，并把读者刚才的输入放回输入框。连接断开时不重新发请求，给一个“恢复”按钮，重新读取已有的讲解。
- **提问。** 回答读者提问的讲解带着那次提问（`asked`），页面把“你的问题”放在它前面，刷新后照样恢复。
- **换论文。** 先按本机已有的论文打开，本机没有再让后端去取。上传的本地 PDF 只在本机，标识可以含中文。
- **选后端和模型。** 点右上角的后端名字打开设置：选用哪个后端；给 Claude Code 或 Codex 选模型（从建议里选、自己填，或者不填，跟随它自己的默认）；调每次生成最多等多少秒（30 到 600）。点“保存”一次写入，下一轮讲解生效。页面不填也不显示密钥。不可用的后端不能选；有讲解正在生成时不能改，要先等它结束或停止它。
- **停止。** 生成中的卡片上有“停止这一轮”。停止后这一轮不保存，也不算读过。
- **留着的问题。** 提问的那一轮先给了导读、没讲成或被停止时，问题留在后端，页面把它显示在最后，刷新后也在；下一次点“继续”会回答它，想换就直接重新提问。
- **路线图。** 导读里的阅读路线画成竖向的路线图，标出现在讲到哪一站。位置文字里认得出页码（PDF）或位置编号（HTML）的站点可以点，左边的原文跳到那里；认不出来的保持普通文字。
- **断开后停止。** 页面按论文把正在生成的任务编号记在当前标签页里。连接断开或刷新后，那一轮如果还在生成，出错卡片上除了“恢复”还有“停止这一轮”。
- **概念记录与反馈（M2，后端还没实现）。** 讲解卡片下面有“还是不懂”“卡在这个词”“这个我会”；右上角的“记录”打开概念记录，可以改状态、写备注、删条目、加词。打开论文时记录不是空的，先摆出来让读者确认或修改，确认之前不能继续。请求讲解时带上记录的版本。接口见约定 4.7 节。现在的后端没有这几个接口，页面读不到记录时不显示这一部分，其余照常；样例数据模式下可以完整试用，记录只留在当前标签页里。
- **只有 PDF 的论文。** 左边用 PDF.js 把每一页画在页面里（`js/pdf-view.js`），只画视口附近的页。文字可以选中：选中后点“问这一段”，原文和页码自动填进提问区；也可以照旧手动填页码、粘贴原文。讲解里的页码标签和路线图站点可以点，跳到那一页；讲解引用的原文在页面上用黄色标出（按文字匹配，忽略空白、断行的连字符和大小写，匹配不上就只跳到那一页）。PDF.js 没载入成时退回浏览器自带的阅读器，只能按页跳转。

## 文件

| 文件 | 作用 |
| --- | --- |
| `index.html`、`styles.css` | 页面骨架和样式，支持深色模式和窄屏。 |
| `js/api.js` | 接口层。真实后端和样例数据提供同一组方法。 |
| `js/paper.js` | 左侧论文：显示正文、公式和图注，标出讲解对应的位置，读取读者选中的原文。 |
| `js/pdf-view.js` | 只有 PDF 的论文：逐页画出来，铺上可以选中的文字层，跳页，标出引用的原文。 |
| `js/cards.js` | 右侧讲解：把讲解对象显示成卡片。 |
| `js/rich.js` | 文字处理：转义、少量 Markdown、公式。论文和讲解的文字都当作数据，先转义再显示。 |
| `js/manage.js` | 换论文、打开本地 PDF、选模型后端。 |
| `js/record.js` | 概念记录与反馈：记录的编辑区、打开时的确认、卡片下面的反馈按钮。 |
| `js/app.js` | 页面主逻辑。 |
| `mock/` | 样例数据，同时是后端结构校验的测试用例。 |
| `dev/fixture_server.py` | 联调用的固定输出服务。 |
| `vendor/` | 第三方库的本地拷贝：公式渲染用的 KaTeX，显示 PDF 用的 PDF.js。版本、许可和核对方法见 [vendor/README.md](vendor/README.md)。 |

## 样例数据

- `mock/paper-2610.27436v1.json`：论文正文，取自 arXiv:2610.27436v1（Juan A. Cañas、Guo-Qing Zhang、A. Martín-Ruiz），按 CC BY 4.0 使用。行内公式是 arXiv HTML 的替代文字，图没有收录。
- `mock/explanations-2610.27436v1.json`：一份导读和两轮讲解，改写自 `examples/` 下的开发样例。读者背景和概念状态都是模拟的，不是真实阅读记录。三份讲解按顺序能通过后端的校验：结构完整，每一份讲的位置是上一份说的“接下来”的位置，外部来源在论文的参考文献里。只有一处依赖模拟的档案：第三份把“非厄米哈密顿量”标成“仍不确定”，后端要求读者档案里有同样的记录。

## 还没做的

- 真实模型（2026-11-15）：Codex 能在一两分钟内生成导读（[试跑记录](../docs/m1-round2-live-trial.md)）。Claude Code 起初两次在 600 秒内没有答完；之后固定推理强度为 high、选 sonnet 重试，同一篇 17 页的 PDF 用了约 1.5 到 2.5 分钟完成，其中 50 到 90 秒是内容已经到齐后等上游的结束信号（[诊断记录](../docs/claude-timeout-diagnosis.md)）。600 秒超时没有再出现，但原因没有确证；默认的 Opus 没有重试。讲解质量还没有人工核对过。
- 留着的问题只能用新问题顶替，不能撤回。
- 只有 PDF 的论文：扫描件没有文字层，只能看，不能选字和高亮；没有缩放按钮，页面宽度跟着左边面板走；PDF 里没有内嵌字体时（少数旧文件和部分中文 PDF），字形可能不对，因为 PDF.js 的备用字体和字符映射文件没有放进来，本地服务目前也不提供这几种文件类型。
- 往页面上拖 PDF 是用模拟的拖放事件测的，没有用真实的鼠标拖一次。
- 样例数据模式下没有论文列表、上传和后端设置。
- 图只显示图注和“看原图”的链接，不显示图片。
- 概念记录与反馈只在样例数据上验证过，等后端实现后再联调；“还是不懂”之后重讲同一点、讲解按记录调整讲法，都要后端和模型配合，页面这边看不出效果。
- 地图、旁问，见接口约定第 7 节的里程碑。
