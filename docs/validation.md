| --- | --- |
| `fetch 2610.27436v1` | arXiv HTML；54 个正文段落 + 1 个摘要，10 个公式、7 个图注，未混入参考文献条目。 |
| `fetch 1002.3895` | API 解析为 `1002.3895v2`；arXiv HTML，104 个段落条目（含摘要）、18 个公式、20 个图注。 |
| `fetch 2610.27849` | API 解析为 `2610.27849v1`；HTML 404、ar5iv 跳到摘要页，正确退回 PDF；结构化段落为空。 |
| 再次 `fetch 2610.27436v1` | `cached=true`，共享请求时间戳未变化；离线测试另通过禁止网络的假客户端验证缓存路径。 |
| `locate 2610.27436v1 "How does a localized, non-Hermitian defect affect"` | 第一候选为 `S1.p4.s6`，得分 1.0。 |
| `find 2610.27436v1 "winding number" --after S1.p4` | 17 个位置，均在该段之后；原文顺序验证通过。词匹配本身不证明语义相同。 |

缓存来源的 SHA-256 前缀，供本地复核：`2610.27436v1` HTML `8b3220769ee4`；`1002.3895v2` HTML `c42f6a02a94c`；`2610.27849v1` PDF `4361a6832be6`。网页以后重新转换可能改变字节，版本号与来源记录仍需一同保留。

首次联网时发现本机 python.org 版 Python 的默认根证书为空。工具只在 macOS 且没有显式证书设置、默认信任根为空时加载 `/etc/ssl/cert.pem`；始终保留 HTTPS 证书校验。随后三种来源均获取成功。

## 对实现说明的明确补充

1. ar5iv 请求也带版本号，并核对最终 URL，避免把未知版本的 HTML 记成指定版本；不能确认版本时退回指定版本 PDF。
2. `profile mark … known` 增加必需的 `--source`，保存读者明确确认的依据。`log add … --json -` 支持从标准输入读 JSON，避免复杂文本的 shell 引号问题。
3. 每个正文、公式和图注条目包含原文顺序字段，支持 `find --after`；保留来源哈希便于本地检查。
4. 不带版本号时优先使用最高的已缓存版本。只有 `--refresh` 才查询最新版本；这是离线复用约定，不代表缓存一定是线上最新版。

锁文件会在正常退出和捕获到的异常后清理。若进程被强制终止，可能留下锁；先确认对应进程已停止，再移除错误信息指出的锁文件。工具不会自动抢占其他正在运行的读写操作。
