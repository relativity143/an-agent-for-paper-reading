## 对实现说明的明确补充

1. ar5iv 请求也带版本号，并核对最终 URL，避免把未知版本的 HTML 记成指定版本；不能确认版本时退回指定版本 PDF。
2. `profile mark … known` 增加必需的 `--source`，保存读者明确确认的依据。`log add … --json -` 支持从标准输入读 JSON，避免复杂文本的 shell 引号问题。
3. 每个正文、公式和图注条目包含原文顺序字段，支持 `find --after`；保留来源哈希便于本地检查。
4. 不带版本号时优先使用最高的已缓存版本。只有 `--refresh` 才查询最新版本；这是离线复用约定，不代表缓存一定是线上最新版。
