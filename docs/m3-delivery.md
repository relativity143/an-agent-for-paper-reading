## 接口与持久化

| 接口 | 成功响应 | 错误 |
| --- | --- | --- |
| `GET /api/papers/<paper>/map` | `{version, nodes, notes}`；未保存过返回 `{version:0,nodes:[],notes:[]}`，不创建持久化文件 | 损坏或无法读取的地图返回 400，保留原文件 |
| `PUT /api/papers/<paper>/map` | 请求和响应均为完整 `{version, nodes, notes}`；原子整份替换 | 非法字段或值 400；版本过期 409；非同源 403 |

沿用其他论文接口的边界：不存在或缓存损坏的论文返回 400；“存在论文但地图未保存”是 200 空地图，不是 404。HTTP 仍支持 HEAD、Host/Origin 检查、请求体限制和异常脱敏。

位置保存在 `PAPERREAD_HOME/papers/<paper>/map-layout.json`，与阅读状态共用 `.agent.lock`，但不放进 `agent-state.json`。读、版本检查、内容比较和原子替换在同一把文件锁内完成。不同 Application 实例同时保存同一版本时，只有第一个能成功，另一个返回 409；不覆盖后来保存的数据。

地图有自己的版本，与 M2 概念记录版本完全独立。内容没有变化时不写文件、不加版本；清空已有地图后版本继续递增，不回到 0。节点或批注列表仅重排视为内容不变，返回原保存顺序；真实修改按请求顺序保存。

严格校验：

- 顶层只接受 `version/nodes/notes`，全部必填；版本为非负整数，布尔值和浮点数不接受。
- 节点只接受 `name/x/y`；名字去掉首尾空白后 1–80 字符，不分大小写去重，最多 400 条。不查概念记录：尚未讲过或已从记录删除的概念也能留位置。
- 批注只接受 `id/x/y/text`；id 原样为 1–40 个 ASCII 字母、数字、下划线或短横线，按区分大小写的 id 去重。正文 1–300 字符，拒绝全空白，但保留有效正文的首尾空白与换行；最多 60 条。
- 所有坐标为整数，x 在 0–1440、y 在 0–900，含边界；拒绝布尔值、浮点数、字符串、NaN/Infinity 和越界值。不截断或自动挪动坐标。
- 存量文件 JSON 或字段不合法、或者是符号链接时，报错并保留原文件；不回退为空地图、不修复覆盖。原子替换失败同样保留旧文件并清理本次临时文件。

## 与阅读功能的隔离

生成讲解期间可以保存地图，不经过 M2 的“生成期间禁止修改概念记录”检查。模型返回后只写自己的阅读状态文件，不会覆盖地图。地图保存不读取或更新概念记录、历史、旧 `profile.json` 或日志；其内容和版本都不进入模型材料。保存前后，已有阅读文件的字节与构造出的提示完全不变。

这轮没有新增 `explain` 请求字段，没有更改 `backend.generate(prompt,schema)`、提示末尾的“本轮材料（JSON 数据）：”、M2 反馈、重试次数或 high effort。

## 页面保存与恢复（2026-11-16）

本轮保持 `GET/PUT /api/papers/<paper>/map` 的请求和响应不变，直接对接已经存在的后端。

- 只在接口缺失（404）或静态样例没有地图 API 时使用浏览器存储。不把网络错误、坏地图、空或非法响应当作一张新地图；读取失败保留已有内容，暂停编辑并提供重新读取入口。
- 同一页面最多一个保存请求在途。连续拖动或输入时合并待保存改动，前一份返回后使用最新版本提交下一份，避免自己与自己产生 409。明确显示待保存、正在保存与已保存。
- 保存失败保留页面草稿，点击“重试保存”才重试；不自动转存浏览器。409 保留草稿、停止继续覆盖，读者可先复制批注，再明确放弃草稿并读取最新地图。重读失败也保留原草稿。
- 未填写的纸条不会发给后端，因此不妨碍其他位置和批注保存。清空已写批注后保存为删除。旧浏览器缓存中的空纸条按旧页面行为忽略，不改变远程字段校验，也不自动迁移本地数据。
- 关闭地图时提交待保存改动；尚未保存时离开或刷新页面有浏览器提示。保存请求未确认成功前不会显示“已保存”；强制退出浏览器无法保证内存草稿保留。
