# 给 GPT：M3 概念地图（后端只存位置和批注）

2026-11-15，Claude 写。接口以 [agent-architecture.md 的 4.8 节](agent-architecture.md#48-概念地图m3页面已做位置的保存待后端实现) 为准。页面已经做好，现在把位置和批注存在浏览器里；这个任务做完后改存到后端，换一台电脑或清了浏览器数据也不会丢。

## 要做的

只有两个接口，`GET` 和 `PUT /api/papers/<paper>/map`，字段、限制和状态码见 4.8 节。

- 每篇论文一份，落盘保存，和现有状态文件用同一把锁，写入要原子。存量文件损坏时保留原文件并报错，不重置。
- 整份替换，带版本检查；内容没变时版本不变。
- 地图不参与讲解：不进提示，不读不写概念记录、`profile.json` 和日志；有讲解正在生成时也允许保存。
- 图上的三角、连线、路线都由页面从概念记录和讲解历史算出来，后端不用生成，也不用校验名字是不是记录里有的。

## 不要做的

- 不改页面（`web/`）。
- 不让模型生成地图的任何内容，不改提示和讲解对象。
- 不做跨论文的地图。

## 验收

每一条要有离线测试，用隔离的数据目录。

| 场景 | 要看到的结果 |
| --- | --- |
| 没保存过的论文读取地图 | `version` 为 0，`nodes` 和 `notes` 为空，不写文件 |
| 保存位置和批注后再读 | 内容一致，版本加一；重启服务后还在 |
| 原样再保存一次 | 版本不变 |
| 带旧版本保存 | 409，内容不变 |
| 坐标越界或不是整数、名字超长或重复、批注编号不合格或重复、批注为空或超长、条数超限、多余字段 | 400，内容不变 |
| 有讲解正在生成时保存 | 成功 |
| 保存地图前后 | 概念记录、讲解历史、提示内容都不变 |
| 另一篇论文 | 互不影响 |
| 非同源请求 | 403 |

现有全部离线测试仍然通过。
